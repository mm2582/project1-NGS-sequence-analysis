# project1-NGS-sequence-analysis
This project simulates part of a next-generation sequencing (NGS) data analysis workflow, in which sequencing reads are compared with a known reference sequence to identify nucleotide differences, or mismatches. These mismatches can then be used to identify and characterise mutations within the sequenced DNA.
You will need Google Colab library, which is installed separately. Then download this notebook: (https://colab.research.google.com/github/doran-amos/C7147-project-practical/blob/main/notebooks/C7147_Project_1_assessment.ipynb) then open it and run it.
